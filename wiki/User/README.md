## The 60-second version

1. Open the app. A short loading screen preloads the data, map, and fonts (you
   can **Skip** it on a slow connection, or turn on [Lite Mode](Lite-Mode.md) to
   skip the heavy parts entirely), then you'll see a welcome screen with an ASCII
   map and a **Play** button. A 20-question, Flag → Country quiz is selected by
   default.
2. Pick a different [game mode](Game-Modes.md) in the top bar if you like.
3. Hit **Play**, then click (or press `A`–`H` / `1`–`9`) to answer each question.
4. Press **Next** (or `Enter`) to advance. At the end you'll see your score,
   accuracy, and best streak — and you can retry the ones you missed.

That's it. The rest of this wiki goes deeper.
